Reflection

學習心得與核心反思

1. 地球物理學的返璞歸真：簡單物理模型的巨大力量

原以為淺層地震探勘需要昂貴極致的裝置與深奧的方程式。經過五週實作後發現：核心僅是活用國小就學過的「光的折射原理（斯乃爾定律）」。透過簡單的幾何關係與走時曲線，就能推算校園地底岩盤深度與波速，體會到基礎知識在實務應用上的巨大價值！

2. 重構地震災害認知：表面波與「建築共振效應」

以往誤以為 S波是造成倒塌的主因，這次課程矯正了觀念：集中在地表傳播且衰減慢的表面波（雷利波與洛夫波）才是災害關鍵。此外，破壞力取決於震波頻率與建築物自然頻率是否吻合（共振）。

透過 IRIS 動畫與「黏土搭配不同長短竹籤」的實驗驗證，切身體會到不同樓層在特定震波頻率下的振動劇烈程度，大幅開闊了防災教育的眼界。

3. AI 工具引領學習典範轉移：從問答機器人到 Agent 操控

改變了過去僅把 AI 當成搜尋對話框的習慣，學會透過 Prompt Engineering 引導 AI Agent 操作 Antigravity IDE 自動建置專案，以及編撰 `.md` 格式文件。結合 GAS 自動化收集與 GitHub Pages 雲端部署，完成全流程的數位學習產出。
